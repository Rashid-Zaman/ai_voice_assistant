# AI Voice Assistant

A multilingual AI Voice Assistant built using Streamlit, Faster-Whisper, Qwen, and Kokoro TTS.

## Features

* Speech-to-Text using Faster-Whisper
* Language Detection
* Translation Support
* AI Response Generation using Qwen
* Text-to-Speech using Kokoro TTS
* Streamlit-based User Interface

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
